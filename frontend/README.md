# ShopKart frontend

The frontend is a React 19 application built with Vite.

## Setup

```sh
npm install
```

Copy `.env.example` to `.env` if the backend API is not running at `http://localhost:5000`. Set `VITE_API_URL` to the backend origin, without a trailing slash.

Start the development server:

```sh
npm run dev
```

Build and lint:

```sh
npm run build
npm run lint
```

See the repository [README](../README.md) for MongoDB, backend, payment gateway, and administrator setup.
